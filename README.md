# مهیار ایمیج تولز

ابزار شخصی تصویر: عکس تمام‌صفحه، انتخاب ناحیه با ماوس، خواندن متن فارسی و انگلیسی، کپی با یک کلیک، و ذخیرهٔ PNG.

دو خروجی ویندوز از گیت‌هاب ساخته می‌شود:

| فایل | چیست |
| --- | --- |
| `Mahyar-Image-Tools-Setup.exe` | نسخهٔ نصبی، با میانبر دسکتاپ و منوی استارت |
| `Mahyar-Image-Tools-Portable.exe` | نسخهٔ پرتابل، بدون نصب اجرا می‌شود |

## ساخت روی گیت‌هاب

1. یک مخزن تازه بساز.
2. همین پروژه را آپلود کن. پوشهٔ `node_modules` را نفرست؛ فایل `.gitignore` آن را کنار می‌گذارد.
3. از تب **Actions** ورک‌فلو **Windows** را یک بار اجازه بده. اگر خودش شروع نشد، **Run workflow** را بزن.
4. وقتی تمام شد، پایین همان اجرا بخش **Artifacts** فایل `Mahyar-Image-Tools-Windows` را دانلود کن. داخلش هر دو exe است.

شاخه باید `main` یا `master` باشد. هر پوش جدید به همان شاخه دوباره بیلد می‌گیرد.

ویندوز ممکن است SmartScreen نشان بدهد، چون فایل امضای پولی ندارد. **More info** و بعد **Run anyway**.

## میانبرها

برنامه باید باز باشد. در نسخهٔ ویندوز میانبر سراسری است، حتی اگر پنجره پشت برنامه‌های دیگر باشد.

- ناحیه: `Ctrl+Shift+S`
- تمام‌صفحه: `Ctrl+Shift+F`

از داخل برنامه می‌توانی به `Alt` یا `PrintScreen` عوضش کنی. اگر ویندوز آن کلید را گرفته باشد، برنامه خبر می‌دهد.

## متن عکس

مدل فارسی و انگلیسی داخل خود برنامه است و برای خواندن متن به اینترنت نیاز ندارد. اولین بار کمی طول می‌کشد. متن را می‌توانی قبل از کپی ویرایش کنی.
